WombCare

Fetal wellness monitoring · Android app

Download for Android

Version 0.1.0 · ~14 MB · Android 8.0+

How to install
  1. Tap Download for Android above on your phone.
  2. Open the downloaded wombcare.apk file.
  3. If asked, allow "Install from this source" — this is normal for apps outside the Play Store.
  4. Tap Install, then Open.
Try it without a device
  1. Sign up as an expectant mother.
  2. Demo mode is on by default — tap Start monitoring to see a live sample session with real charts and an alert.
  3. To link a doctor: open Share, and on a second phone sign up as a doctor and paste the code.
WombCare is a home wellness-awareness aid — not a medical device. It does not diagnose any condition and does not replace clinical care.
